# Grove

Spot changes in thinking early.

Grove is a short, caregiver-guided check-in for assisted living and memory care. A resident plays a 3-4 minute game, and Grove tracks their results over time so no change in thinking goes unnoticed.

Built at [Hackathon name] by Faaizah, Shreya, Qiqi, and Nivedita.

## The Problem

My grandpa plays brain games every day. He wants to know his mind is still sharp, so he keeps track himself.

Many seniors can't. In care homes, that job falls to busy caregivers, using paper tests done months apart.

## How It Works

1. **Play:** A caregiver sits with the resident for a 3-4 minute game.
2. **Save:** Every score is saved automatically, with no added paperwork for caregivers.
3. **Compare:** Each result is checked against the resident's own normal.
4. **Flag:** When the trend changes, the care team is alerted. Grove never diagnoses.

## Features

### For Residents
- Large text, readable without glasses
- Large buttons, easy to hit with arthritis or a tremor
- Stylus friendly, for residents who find touch hard
- A game, not a test, with short stories, streaks, and levels

### For Caregivers
- Every result over time, compared to the resident's own baseline
- A flag when the trend changes
- The most urgent residents shown first
- A suggested next step, never a diagnosis

## Who It's For

- **Built for:** Residents of assisted living and memory care, including those with no diagnosis, mild cognitive impairment, or moderate dementia.
- **Not for:** Independent seniors living at home.
- **Next:** Advanced dementia, where a tablet-based solution may not work.
